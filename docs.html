Core Engine Architecture

The master class is AgentPrahari. It coordinates input canonicalization, PII redaction, prompt injection filtering, tool validation, loop detection, and secret leakage defense. 

from agentprahari import AgentPrahari

# Initialize with preset:
shield = AgentPrahari.from_preset("strict")

Security Presets

AgentPrahari provides 5 audited presets suited for different enterprise workloads:

strict (Default): Maximum security for public-facing customer applications. Masks PII, blocks all injection risks, and restricts dangerous tools.
moderate: Balanced protection for internal employee copilots.
code_agent: Tailored for developer tools and coding assistants. Permits code syntax, technical IPs, and compiler commands while blocking destructive operations (rm -rf, formatting).
financial: Enforces PCI-DSS credit card Luhn validation, strict audit logging, and human-in-the-loop approvals.

validate_input(prompt, client_id="default")

Runs pre-execution checks on a user prompt or external RAG context. Returns an immutable GuardResult. 

result = shield.validate_input("Ignore instructions")

if result.decision == ActionDecision.BLOCK:
    print("Blocked:", result.rejection_reason)
elif result.decision == ActionDecision.SANITIZE:
    print("Sanitized safe text:", result.sanitized_content)

Note: evaluate_input() is supported as a 100% compatible direct alias.

validate_tool_call(tool_name, tool_args=None)

Evaluates impending agent actions before tool dispatch. Intercepts destructive shell operations, SQL drops, path escapes, and loops. 

res = shield.validate_tool_call("bash", {"cmd": "rm -rf /"})

if not res.is_valid:
    raise DangerousToolCallError(res.rejection_reason)

Note: evaluate_tool_action() and evaluate_tool_call() are direct aliases.

shield.wrap(client)

1-line drop-in wrapper for standard OpenAI and Anthropic SDK client instances. Automatically checks prompts before transmission and scrubs model completions before returning. 

from openai import OpenAI

client = shield.wrap(OpenAI())
# Ready to use with automatic guardrails!

PrahariMiddleware (FastAPI / ASGI)

Standard ASGI middleware for FastAPI, Starlette, and Quart. Transparently inspects incoming request JSON payloads, strips PII, and returns HTTP 400 on attacks. 

from fastapi import FastAPI
from agentprahari.middleware import PrahariMiddleware

app = FastAPI()
app.add_middleware(PrahariMiddleware, preset="strict")

CLI Sandbox Reference

Command-line interface commands available for terminal testing and CI/CD scripting: 

# Inspect input prompt:
agentprahari check "prompt text" [--preset strict] [--json]

# Inspect tool call:
agentprahari check-tool bash "rm -rf /"

# Inspect model output for secret leaks:
agentprahari check-output "response text"

# Measure CPU micro-latency:
agentprahari benchmark
