The Architecture

Three Security Checkpoints

Nothing skips the line. User inputs are sanitized before reaching your model, tool calls are verified before execution, and outputs are scrubbed before leaving your system.

First Gate

Input Firewall

Normalizes multi-layer URL/HTML/Unicode encodings, then screens prompts for injection, persona jailbreaks, and harmful topics. Customer PII and credit cards are safely masked.

  • Multi-layer URL & Homoglyph Normalizer
  • Instruction Hierarchy & Delimiter Defense
  • Luhn-Validated PCI-DSS & PII Redaction
  • Educational Trojan & RAG Poisoning Shield
Second Gate

Tool Execution Guard

Autonomous agents with shell or database access are verified before every single action. Destructive commands, SQL drop injections, and runaway loops are stopped before execution.

  • Destructive Shell Filter (rm -rf, mkfs, fork bombs)
  • Literal-Aware SQL Comment & DDL Parser
  • Sliding-Window Cycle & Loop Circuit Breaker
  • Human-In-The-Loop (HITL) Privilege Gates
Third Gate

Output Firewall

Before a response leaves your server, it is scrubbed for high-entropy API keys, base64url JWT tokens, database passwords, and echoed system prompt extractions.

  • Structural 3-Part JWT & API Token Redactor
  • System Prompt Similarity & Extraction Guard
  • Markdown JSON Code-Fence Stripper & Repair
  • RAG Grounding & Hallucination Verification

Zero-Code Friction

Fits Directly Into Your Existing Codebase

No proxies to configure. No extra microservices to manage. Pick your framework below and secure your AI traffic in minutes. 

from openai import OpenAI
from agentprahari import AgentPrahari

# 1. Initialize AgentPrahari with a security preset
shield = AgentPrahari.from_preset("strict")

# 2. Wrap your client in ONE line — zero application rewrites needed:
client = shield.wrap(OpenAI())

# 3. Call your model normally!
# - Injections are blocked automatically before leaving your server
# - PII is masked, and leaked API keys/JWTs are scrubbed from outputs
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "My email is alice@corp.com"}]
)

print(response.choices[0].message.content)
from fastapi import FastAPI
from pydantic import BaseModel
from agentprahari.middleware import PrahariMiddleware

app = FastAPI(title="Secure LLM Gateway")

# Attach AgentPrahari ASGI middleware across all routes:
app.add_middleware(
    PrahariMiddleware,
    preset="strict",
    input_keys=("prompt", "message", "query", "text"),
    auto_sanitize=True,
)

class ChatRequest(BaseModel):
    message: str

@app.post("/api/chat")
async def chat_endpoint(request: ChatRequest):
    # 'request.message' is ALREADY guarded:
    # Attacks receive HTTP 400 rejection; PII is safely redacted
    return {"reply": f"Safe query: {request.message}"}
from langchain_openai import ChatOpenAI
from agentprahari import PrahariCallbackHandler

# Attach safety callbacks directly to any LangChain LLM or AgentExecutor:
llm = ChatOpenAI(
    model="gpt-4o",
    callbacks=[PrahariCallbackHandler(preset="strict")]
)

# Prompts, tool actions, and generations are validated transparently!
response = llm.invoke("What is machine learning?")
